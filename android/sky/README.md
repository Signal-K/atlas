# Sky engine (Android)

Kotlin port of the sky pointing maths in `ios/AtlasCore` (`SkyCamera`, `SkyStabilizer`). Pure JVM, no
Android classes, so it tests anywhere: `gradle test` in this folder. The Android app depends on this
module and adds the sensor adapter below.

`../../sky-engine/golden.json` is generated by the Swift tests (`GENERATE_GOLDEN=1 swift test --filter
SkyGoldenTests` in `ios/AtlasCore`) and replayed by both platforms. If you change the algorithm, change
both ports and regenerate; a mismatch fails CI on whichever side was not updated.

## Wiring the sensors (app side)

```kotlin
// Rotation vector fuses accelerometer + gyro + magnetometer; the gyro is used for the still/moving gate.
val rotationVector = sensors.getDefaultSensor(Sensor.TYPE_ROTATION_VECTOR)
val gyro = sensors.getDefaultSensor(Sensor.TYPE_GYROSCOPE)
val stabilizer = SkyStabilizer()
var rate = 0.0
val declination = GeomagneticField(lat, lon, altMeters, System.currentTimeMillis()).declination.toDouble()

override fun onSensorChanged(e: SensorEvent) = when (e.sensor.type) {
    Sensor.TYPE_GYROSCOPE -> rate = sqrt((e.values[0] * e.values[0] + e.values[1] * e.values[1] + e.values[2] * e.values[2]).toDouble())
    else -> {
        val r = FloatArray(9)
        SensorManager.getRotationMatrixFromVector(r, e.values)
        val raw = AndroidFrames.cameraRotation(DoubleArray(9) { r[it].toDouble() }, declination)
        camera = SkyCamera(stabilizer.filter(raw, rate, e.timestamp / 1e9))
    }
}
// Register both at SENSOR_DELAY_GAME. Lock the activity to portrait (android:screenOrientation="portrait").
```

Compass calibration: listen to `onAccuracyChanged` for the rotation vector and show "wave your phone in a
figure 8" when accuracy is `SENSOR_STATUS_ACCURACY_LOW` or below (the iOS `needsCompassCalibration`).
