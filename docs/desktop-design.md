# Desktop feed — ASV-150

## Scope

Start with only the main feed. The previous desktop workspace is discarded.

## Reference

The author's reference is plate.to. Its page could not be accessed from this environment. Exact reference matching remains pending a screenshot or accessible copy; the rules below record the explicitly requested reset, not a claimed analysis of plate.to.

## Composition

One centred reading column, at most 640px wide. Minimal Atlas wordmark and location control. Feed entries contain category, date, title, optional source image, description, and save action. Entries are separated by thin rules, not dashboard cards.

No desktop sidebar, calendar column, campaign banner, guest banner, dashboard, marketing headline, tab bar, or floating feedback controls.

## Styling

A flat neutral background. No gradients, coloured darkness, green tint, glass, shadows, accent washes, or decorative card containers. Text and dividers use neutral greys. Preserve a sparse monochrome starfield behind the feed. Use a simple sans-serif typeface with restrained sizes.

The desktop feed has its own markup and stylesheet and bypasses the legacy shell. Existing storage and event data power the feed; they are not replaced with mock application data.
