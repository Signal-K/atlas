# Desktop interface

The current visual specification is [design.md](../design.md), based on the author's three plate.to screenshots. The background-only reset and previous desktop dashboard have been replaced by the new app interface.

Implemented screens: Feed, Collections, Calendar, Journal, Account, plus location selection and event-detail dialogs. The starfield is continuous behind the transparent document and labeled sidebar. Branding is the Atlas wordmark; no Plate logo is used.
